ax² + bx + c = 0, cu explicația fiecărui pas și grafic live.

Orice ecuație de forma ax² + bx + c = 0 (cu a ≠ 0) se rezolvă cu formula:

Formulăx = (−b ± √(b²−4ac)) / 2a

Semnul discriminantului Δ = b² − 4ac spune ce fel de rădăcini are ecuația: două rădăcini reale dacă Δ>0, o rădăcină dublă dacă Δ=0, sau două rădăcini complexe dacă Δ<0.
