Funcția Möbius

August Ferdinand Möbius, 1832 · nr. 145

Definiție: Funcția Möbius μ(n) este definită astfel: μ(1)=1; μ(n)=0 dacă n are un factor prim la pătrat (n nu este liber de pătrate); μ(n)=(−1)^k dacă n este liber de pătrate și are exact k factori primi distincți.
Formulăμ(n)=(−1)^k dacă n liber de pătrate cu k factori primi; μ(n)=0 altfel
Imaginea din spatele formulei
Gândește-te la μ(n) ca la un joc de comutatoare: pornești de la +1, iar fiecare factor prim diferit al lui n întoarce comutatorul (din +1 în −1 sau invers). Dacă vreun factor prim apare de două ori sau mai mult, jocul se „strică” instant și rezultatul devine automat 0 - de exemplu 12=2²×3 are factorul 2 repetat, deci μ(12)=0, indiferent de restul factorilor.
Funcția Möbius este multiplicativă: μ(mn)=μ(m)μ(n) dacă gcd(m,n)=1. Stă la baza formulei de inversiune Möbius și a identității 1/ζ(s)=∑μ(n)/nˢ.
1
Calculează μ(30).

Descompunem 30 în factori primi: 30=2×3×5.

Niciun factor prim nu se repetă, deci 30 este liber de pătrate, cu k=3 factori primi distincți.

Aplicăm formula: μ(30)=(−1)³=−1.

✓ μ(30) = −1
2
Care este cel mai mic număr natural n>1 pentru care μ(n)=0?

μ(n)=0 exact atunci când n are un factor prim ridicat la o putere de cel puțin 2 (n nu este liber de pătrate).

Pentru n=2 și n=3, fiecare are un singur factor prim la puterea 1, deci μ(2)=μ(3)=−1, nu 0.

Cel mai mic număr cu un factor prim repetat este pătratul celui mai mic număr prim: 2²=4.

✓ n = 4 (cel mai mic număr cu μ(n)=0)
3
Cât este μ(1), cazul special de la baza definiției?

Prin definiție, μ(1)=1, independent de orice factorizare, pentru că 1 nu are niciun factor prim.

Acesta este cazul de bază (k=0 factori primi, considerat „par” prin convenție), necesar ca formula de inversiune Möbius să funcționeze corect pentru toate numerele.

✓ μ(1) = 1
4
Adevărat sau fals: μ(n) este întotdeauna diferit de 0 dacă n este liber de pătrate (fără niciun factor prim repetat).

Prin definiție, μ(n)=0 doar atunci când n are un factor prim la pătrat, adică nu este liber de pătrate.

Dacă n este liber de pătrate, μ(n) este fie (−1)^k cu k par (deci +1), fie cu k impar (deci −1) - niciodată 0.

De exemplu, 30=2×3×5 este liber de pătrate și μ(30)=(−1)³=−1, diferit de 0, exact cum spune afirmația.

✓ Adevărat - μ(n)≠0 exact atunci când n este liber de pătrate.
5
Un matematician afirmă că suma μ(d), pentru toți divizorii d ai lui n, este întotdeauna 0 atâta timp cât n>1. Verifică afirmația pentru n=12.

Găsim toți divizorii lui 12: 1, 2, 3, 4, 6, 12.

Calculăm μ pentru fiecare: μ(1)=1, μ(2)=−1, μ(3)=−1, μ(4)=0, μ(6)=1, μ(12)=0.

Adunăm toate valorile: 1−1−1+0+1+0=0.

✓ Suma este 0, confirmă afirmația pentru n=12.
