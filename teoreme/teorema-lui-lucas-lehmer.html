Testul Lucas–Lehmer

Édouard Lucas, 1878 / Derrick H. Lehmer, 1930 · nr. 144

Enunț: Fie p un număr prim și Mₚ=2ᵖ−1 numărul Mersenne corespunzător. Se definește șirul S₀=4, Sₙ₊₁=Sₙ²−2. Atunci Mₚ este prim dacă și numai dacă Sₚ₋₂ ≡ 0 (mod Mₚ).
FormulăMₚ prim ↔ Sₚ₋₂ ≡ 0 (mod Mₚ), S₀=4, Sₙ₊₁=Sₙ²−2
Imaginea din spatele formulei
Ia un singur număr magic, 4, și joacă un joc: la fiecare rundă, ridică-l la pătrat, scade 2, apoi păstrează doar restul împărțirii la Mₚ (ca pe un ceas cu Mₚ ore). Dacă, după exact p−2 runde, jocul ajunge exact la 0, atunci Mₚ este garantat prim - nu doar „probabil”, ci sigur, fără nicio îndoială.
Testul Lucas–Lehmer este algoritmul folosit de proiectul GIMPS pentru a găsi cele mai mari numere prime cunoscute - toate sunt prime Mersenne, ultimele având peste 24 de milioane de cifre.
1
Aplică testul Lucas-Lehmer pentru p=5 (M₅=31), parcurgând tot șirul Sₙ.

Pornim cu S₀=4.

S₁=4²−2=14.

S₂=14²−2=194; reducem modulo 31: 194−6×31=194−186=8.

S₃=8²−2=62; reducem modulo 31: 62−31=31, 31−31=0, deci 62 mod31=0.

Cum p−2=5−2=3, verificăm exact S₃, care este 0.

✓ S₃≡0 (mod 31) → M₅=31 este prim
2
Testul Lucas-Lehmer pentru un anumit p a necesitat exact 11 iterații ale șirului Sₙ. Care este p, și cât este Mₚ?

Numărul de iterații necesare este întotdeauna p−2.

Punem p−2=11, deci p=13.

Calculăm Mₚ=2¹³−1=8192−1=8191.

✓ p = 13, iar M₁₃ = 8191
3
De ce testul Lucas-Lehmer nu se aplică pentru p=2, deși M₂=2²−1=3 este prim?

Testul Lucas-Lehmer, așa cum este enunțat, cere ca p să fie un număr prim impar (p≥3).

p=2 este singurul număr prim par, deci este exclus explicit din enunțul teoremei.

M₂=3 este într-adevăr prim, dar acest lucru se verifică direct, „la vedere” (3 nu are alți divizori decât 1 și 3), nu prin testul Lucas-Lehmer.

✓ Testul se aplică doar pentru p impar; M₂=3 se verifică separat, direct.
4
Adevărat sau fals: dacă Sₚ₋₂ nu este congruent cu 0 modulo Mₚ, atunci Mₚ este cu siguranță compus, nu doar „probabil” compus.

Testul Lucas-Lehmer este un test „dacă și numai dacă”: Sₚ₋₂≡0 (mod Mₚ) exact atunci când Mₚ este prim.

Dacă Sₚ₋₂ nu este 0 modulo Mₚ, condiția din teoremă nu este îndeplinită, deci Mₚ nu este prim, adică este cu certitudine compus.

Spre deosebire de testele probabilistice (ca Miller-Rabin), Lucas-Lehmer dă un răspuns cert în ambele direcții, nu doar o probabilitate mare.

✓ Adevărat - testul este cert în ambele sensuri (prim sau compus), nu probabilistic.
5
Echipa proiectului GIMPS vrea să verifice dacă M₇=127 este prim, folosind testul Lucas-Lehmer. Parcurge tot șirul Sₙ, pas cu pas, până la concluzie.

Pornim cu S₀=4.

S₁=4²−2=14.

S₂=14²−2=194, iar 194 mod127=194−127=67.

S₃=67²−2=4487, iar 4487 mod127: 127×35=4445, rest 4487−4445=42.

S₄=42²−2=1762, iar 1762 mod127: 127×13=1651, rest 1762−1651=111.

S₅=111²−2=12319, iar 12319 mod127: 127×97=12319, rest 0.

Cum p−2=7−2=5, verificăm exact S₅, care este 0.

✓ S₅≡0 (mod 127) → M₇=127 este prim, confirmat de echipa GIMPS.
