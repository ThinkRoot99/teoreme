Inegalitatea lui Jensen

Johan Jensen, 1906 · nr. 165

Explicații și exerciții: Moldovan Cristian · actualizat 3 octombrie 2026

Enunț: Dacă φ este o funcție convexă și X o variabilă aleatoare cu medie finită, atunci valoarea lui φ în medie este cel mult media valorilor lui φ.
Formulăφ(E[X]) ≤ E[φ(X)] (φ convexă)
Imaginea din spatele formulei
Imaginează-ți un bol rotund, ca o farfurie adâncă. Dacă pui degetul pe marginea bolului într-un loc și tragi o sforicică dreaptă până în alt loc de pe margine, sfoara stă mereu deasupra fundului bolului, niciodată pe dedesubt. La fel se întâmplă cu o funcție „în formă de bol” (convexă): calculată chiar în mijloc, ea dă o valoare mai mică decât media calculelor făcute în fiecare punct. Dacă bolul ar fi întors cu gura în jos (funcție concavă), totul s-ar inversa.
Johan Jensen a publicat-o în 1906. Generalizează inegalitatea mediei aritmetice și geometrice și stă la baza multor rezultate din statistică, teoria informației și optimizare - de exemplu, faptul că entropia e concavă.
1
O variabilă X ia valoarea 1 cu probabilitate 1/2 și valoarea 5 cu probabilitate 1/2. Folosind funcția convexă φ(x)=x², verifică inegalitatea lui Jensen.

Calculăm mai întâi media lui X: E[X] = 1×0.5 + 5×0.5 = 3.

Aplicăm funcția în medie: φ(E[X]) = φ(3) = 3² = 9.

Acum calculăm media funcției: E[φ(X)] = 1²×0.5 + 5²×0.5 = 0.5 + 12.5 = 13.

✓ 9 ≤ 13, inegalitatea lui Jensen se verifică
2
Pentru o variabilă aleatoare X și o funcție φ se știe că φ(E[X]) = 5, iar E[φ(X)] = 3. Ce poți deduce despre forma funcției φ?

Inegalitatea lui Jensen pentru o funcție convexă cere φ(E[X]) ≤ E[φ(X)], adică valoarea calculată în medie trebuie să fie cea mai mică.

Aici avem exact situația inversă: 5 este mai mare decât 3, deci φ(E[X]) depășește E[φ(X)].

Această ordine corespunde cazului în care φ este concavă, pentru care inegalitatea lui Jensen se inversează: φ(E[X]) ≥ E[φ(X)].

✓ φ este (pe acest exemplu) concavă, nu convexă
3
X este o variabilă „constantă”: ia mereu valoarea 4, cu probabilitate 1. Ce se întâmplă cu inegalitatea lui Jensen în acest caz, pentru φ(x)=x²?

Media lui X este chiar valoarea ei constantă: E[X] = 4.

Calculăm φ(E[X]) = φ(4) = 16.

Cum X ia mereu aceeași valoare, și φ(X) ia mereu aceeași valoare, deci E[φ(X)] = φ(4) = 16.

✓ φ(E[X]) = E[φ(X)] = 16: când nu există împrăștiere, inegalitatea devine egalitate
4
Adevărat sau fals: inegalitatea φ(E[X]) ≤ E[φ(X)] este valabilă pentru orice funcție φ, indiferent dacă aceasta este convexă sau nu.

Fals. Inegalitatea lui Jensen, în această formă, este garantată doar pentru funcții convexe.

De exemplu, pentru φ(x)=√x, care este concavă, relația se inversează: φ(E[X]) ≥ E[φ(X)].

Deci forma funcției (bol cu gura în sus sau în jos) decide sensul inegalității.

✓ Fals - direcția depinde de convexitatea sau concavitatea lui φ
5
La un joc de noroc simplu, un jucător câștigă fie 2 lei, fie 8 lei, cu șanse egale. Folosind φ(x)=x², compară media pătratelor câștigurilor cu pătratul mediei câștigurilor.

Media câștigurilor este E[X] = 2×0.5 + 8×0.5 = 5 lei.

Pătratul mediei este φ(E[X]) = 5² = 25.

Media pătratelor este E[X²] = 2²×0.5 + 8²×0.5 = 2 + 32 = 34.

✓ 25 ≤ 34: media pătratelor depășește pătratul mediei, exact cum prezice Jensen pentru φ convexă
