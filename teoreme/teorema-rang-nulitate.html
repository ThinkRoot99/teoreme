Teorema rang–nulitate

Sylvester, 1850 · nr. 099

Enunț (Teorema Sylvester/Rang-Nulitate): Pentru orice transformare liniară f:V→W, suma dimensiunilor nucleului și imaginii egal dimensiunea spațiului sursă.
Formulădim(Ker f) + dim(Im f) = dim(V)
Imaginea din spatele formulei
Ce se „pierde” într-o transformare (nucleul) și ce „rămâne vizibil” (imaginea) se completează exact la mărimea de la care ai plecat - ca un aparat de tocat care „mănâncă” unele direcții complet (le trimite la zero), dar restul ies intacte de partea cealaltă, iar cele două bucăți, împreună, refac exact spațiul inițial.
Rezultatul a fost formulat de Sylvester în 1850 și este echivalent cu teorema rangului pentru matrice: rang(A)+nulitate(A)=n, unde n este numărul de coloane.
1
f:ℝ⁵→ℝ³, rang(f)=2. Cât este dim(Ker f)?

Formula spune dim(Ker f)+dim(Im f)=dim(V), unde aici V=ℝ⁵.

Știm dim(Im f)=rang(f)=2, deci dim(Ker f)=5-2=3.

✓ dim(Ker)=3
2
O matrice 3×4 are dim(Ker)=1. Care este rangul ei?

Aici V=ℝ⁴ (4 coloane), deci dim(V)=4.

Din formulă: rang(A)=dim(V)-dim(Ker)=4-1=3.

✓ rang(A)=3
3
f:ℝ⁴→ℝ⁴ este inversabilă. Cât este dim(Ker f)?

O transformare inversabilă nu trimite niciun vector nenul la 0 (altfel nu ar fi inversabilă), deci Ker(f)={0}, adică dim(Ker f)=0.

Verificăm formula: dim(Ker f)+dim(Im f)=0+4=4=dim(V), consistent cu faptul că imaginea este tot spațiul ℝ⁴.

✓ dim(Ker)=0 (caz limită: transformare bijectivă)
4
Adevărat sau fals: o transformare liniară f:ℝ³→ℝ⁵ poate fi surjectivă (Im(f)=ℝ⁵).

Din teorema rang-nulitate, dim(Im f)≤dim(V)=3, deoarece dim(Ker f)≥0.

Pentru surjectivitate ar trebui dim(Im f)=5, dar 5>3, deci este imposibil - afirmația este falsă.

✓ Fals - imaginea nu poate depăși dimensiunea sursei
5
O cameră foto proiectează o imagine 3D (spațiul de culori RGB, dimensiune 3) pe un ecran plat 2D printr-o transformare liniară f. Ce poți spune despre dim(Ker f)?

Aici dim(V)=3 (spațiul RGB) și, dacă proiecția acoperă tot ecranul, dim(Im f)=2 (spațiul ecranului).

Din formulă: dim(Ker f)=dim(V)-dim(Im f)=3-2=1, adică există o direcție întreagă de „informație” care se pierde complet în proiecție.

✓ dim(Ker f)=1 (o dimensiune de informație pierdută)
