Relațiile lui Viète

François Viète, 1591 · nr. 093

Enunț: Dacă x₁,…,xₙ sunt rădăcinile polinomului aₙxⁿ+…+a₁x+a₀, atunci sumele și produsele lor se exprimă prin coeficienți.
Formulăx₁+x₂=−b/a; x₁·x₂=c/a (grad 2)
Imaginea din spatele formulei
Nu trebuie să găsești numerele exacte ca să afli suma și produsul lor - coeficienții ecuației îți „șoptesc” direct răspunsul, ca o etichetă pe o cutie care îți spune câte jucării sunt înăuntru fără să le numeri.
François Viète a introdus aceste notații algebrice în 1591, iar relațiile care îi poartă numele stau la baza algebrei simetrice și a teoremei funcțiilor simetrice elementare.
1
x²-5x+6=0. Găsește suma și produsul rădăcinilor.

Comparăm cu forma x²-Sx+P=0, unde S este suma și P este produsul rădăcinilor: aici S=5 și P=6.

Verificăm rezolvând ecuația: rădăcinile sunt 2 și 3, iar 2+3=5, 2×3=6, ceea ce confirmă relațiile.

✓ Sumă=5, Produs=6
2
Suma rădăcinilor unei ecuații de gradul 2 este 7 și produsul este 12. Scrie ecuația, fără a afla rădăcinile individuale.

Folosim forma generală x²-(sumă)x+(produs)=0.

Înlocuim valorile cunoscute: x²-7x+12=0.

✓ x²-7x+12=0 (rădăcinile sunt de fapt 3 și 4)
3
x²-6x+9=0. Ce este special la rădăcinile acestei ecuații?

Suma rădăcinilor este 6, iar produsul este 9, conform coeficienților.

Observăm că x²-6x+9=(x-3)², deci ambele rădăcini coincid: x₁=x₂=3 - cazul limită în care discriminantul este zero.

✓ x₁=x₂=3, rădăcină dublă
4
Adevărat sau fals: dacă suma rădăcinilor unei ecuații x²+px+q=0 este pozitivă, atunci ambele rădăcini sunt neapărat pozitive.

Alegem un contraexemplu: ecuația x²-x-6=0, unde suma rădăcinilor este 1 (pozitivă).

Rezolvăm: rădăcinile sunt 3 și -2, iar suma 3+(-2)=1 este pozitivă, dar -2 este negativă - afirmația este falsă.

✓ Fals
5
Un fermier știe că suma lungimii și lățimii unui teren dreptunghiular este 10 metri, iar aria (produsul lor) este 21 m². Fără să rezolve ecuația de gradul doi de la zero, ce ecuație trebuie să scrie pentru a afla laturile?

Folosim relațiile lui Viète invers: dacă S=10 este suma și P=21 este produsul, ecuația este x²-Sx+P=0.

Scriem ecuația: x²-10x+21=0, care se rezolvă și dă laturile 3 și 7 metri.

✓ x²-10x+21=0, laturile sunt 3 și 7 metri
