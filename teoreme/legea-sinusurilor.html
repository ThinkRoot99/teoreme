Legea sinusurilor

Ptolemeu, ~150 d.Hr. · nr. 006

Enunț: Raportul dintre orice latură a unui triunghi și sinusul unghiului opus este constant, egal cu diametrul cercului circumscris.
Formulăa/sinA = b/sinB = c/sinC = 2R
Imaginea din spatele formulei
Toate triunghiurile desenate în același cerc, cu aceeași coardă (adică aceeași latură), au ceva în comun: raportul dintre orice latură și sinusul unghiului opus ei este mereu același număr, egal cu diametrul cercului care trece prin toate cele trei vârfuri. E ca și cum cercul ar „măsura” în secret toate laturile și unghiurile deodată, indiferent de forma triunghiului.
Folosită în triangulația geodezică, navigație maritimă și astronomie pentru a determina distanțe inaccesibile.
1
Într-un triunghi, a = 10, A = 30° și B = 45°. Cât măsoară latura b?

Legea sinusurilor spune că a/sinA = b/sinB.

Calculăm mai întâi raportul comun: a/sinA = 10/sin30° = 10/0,5 = 20.

Aflăm b din acest raport: b = 20 × sin45° = 20 × (√2/2) = 10√2 ≈ 14,14.

✓ b = 10√2 ≈ 14,14
2
Într-un triunghi, latura a = 6 este opusă unghiului A = 60°. Cât măsoară raza R a cercului circumscris?

Pornim de la formula: 2R = a/sinA.

Înlocuim: 2R = 6/sin60° = 6/(√3/2) = 12/√3 = 4√3.

Împărțim la 2 ca să aflăm R: R = 2√3 ≈ 3,46.

✓ R = 2√3 ≈ 3,46
3
Un triunghi dreptunghic are unghiul drept A = 90° și ipotenuza a = 10. Cât măsoară raza cercului circumscris?

La unghi drept, sin90° = 1, deci formula devine 2R = a/1 = a.

R = a/2 = 10/2 = 5.

✓ R = 5. La triunghiul dreptunghic, raza circumscrisă este mereu jumătate din ipotenuză.
4
Adevărat sau fals: dacă doi elevi desenează triunghiuri diferite, dar înscrise în cercuri de aceeași rază R, atunci un unghi de 30° va avea mereu, în ambele triunghiuri, aceeași latură opusă.

Din legea sinusurilor: latura opusă unui unghi de 30° este a = 2R·sin30° = R (pentru orice triunghi înscris în acel cerc).

Cum R este fixat, valoarea lui a este aceeași, indiferent de forma restului triunghiului.

✓ Adevărat. Latura depinde doar de R și de unghi, nu de restul figurii.
5
Un topograf măsoară un unghi de 120° între două repere și unghiul de 30° dintre al doilea reper și un al treilea punct, aflat la 8 km de al doilea reper. Cât de departe este al treilea punct de primul reper (latura c)?

Punem datele în triunghi: latura cunoscută b = 8, opusă unghiului B = 120°; căutăm latura c, opusă unghiului C = 30°.

Legea sinusurilor: c/sinC = b/sinB, deci c = 8 × sin30° / sin120° = 8 × 0,5 / (√3/2) = 4 / (√3/2) = 8/√3.

Calculăm: 8/√3 ≈ 4,62.

✓ Distanța este de aproximativ 4,62 km.
