Cercul înscris triunghiului

Euclid · nr. 014

Enunț: Orice triunghi admite un cerc înscris unic (tangent interior tuturor celor trei laturi), al cărui centru I este intersecția bisectoarelor unghiurilor. Raza r este dată de r = S / s, unde s este semiperimetrul.
Formulăr = S / s, S = s · r
Imaginea din spatele formulei
Imaginează-ți că vrei să umfli cel mai mare balon rotund posibil în interiorul unui triunghi, fără să-l lași să iasă peste margini. Balonul atinge toate cele trei laturi în același timp, iar centrul lui, I, se află la aceeași distanță de fiecare latură - distanța aceea este raza cercului înscris, r.
Centrul cercului înscris (incentrul) este întotdeauna situat în interiorul triunghiului, indiferent de natura unghiurilor sale.
1
Un triunghi dreptunghic are laturile 3, 4, 5. Găsește raza cercului înscris.

Calculăm aria: S = 3×4/2 = 6.

Calculăm semiperimetrul: s = (3+4+5)/2 = 6.

Aplicăm formula r = S/s = 6/6 = 1.

✓ r = 1
2
Un triunghi are semiperimetrul s = 15 și raza cercului înscris r = 3. Cât măsoară aria triunghiului?

Rearanjăm formula: S = s × r.

Înlocuim: S = 15 × 3 = 45.

✓ S = 45
3
Un triunghi echilateral are latura a. Exprimă raza cercului înscris în funcție de a.

Semiperimetrul este s = 3a/2, iar aria este S = a²√3/4.

Aplicăm formula: r = S/s = (a²√3/4) / (3a/2) = a²√3/4 × 2/(3a) = a√3/6.

✓ r = a√3/6
4
Adevărat sau fals: centrul cercului înscris se poate afla uneori în afara triunghiului, la fel ca centrul cercului circumscris.

Cercul înscris este definit ca fiind tangent la toate cele trei laturi, din interior.

Un asemenea cerc nu poate exista decât în interiorul triunghiului, indiferent de forma acestuia (ascuțit, drept sau obtuz).

✓ Fals. Centrul cercului înscris este mereu în interiorul triunghiului.
5
Compară r și R (raza cercului circumscris) pentru triunghiul dreptunghic 3-4-5.

Din exercițiul anterior, r = 1.

Pentru triunghiul dreptunghic, R = ipotenuza/2 = 5/2 = 2,5.

Raportul este r/R = 1/2,5 = 0,4.

✓ r/R = 0,4. Raza înscrisă este mereu mai mică decât cea circumscrisă.
