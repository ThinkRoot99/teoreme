Teorema lui Pitagora

Pitagora, ~570 î.Hr. · nr. 002

Ipoteză: Fie un triunghi dreptunghic cu catetele a, b și ipotenuza c (latura opusă unghiului drept).

Concluzie: Suma pătratelor catetelor egalează pătratul ipotenuzei.
Formulăa² + b² = c²
Imaginea din spatele formulei
Imaginează-ți trei covorașe pătrate, câte unul lipit de fiecare latură a unui triunghi cu un colț drept (exact ca un colț de carte sau de fereastră). Dacă tai cele două covorașe mici în bucăți și le așezi peste covorașul mare, îl acoperă exact, fără să rămână loc gol și fără să se suprapună. Se întâmplă mereu, la orice triunghi cu colț drept, oricât de mare sau de mic ar fi el.
Tripletul (3,4,5) era folosit de constructorii din Egiptul antic (~2000 î.Hr.) cu o frânghie cu 12 noduri egale pentru a trasa unghiuri drepte perfecte.
1
Catetele unui triunghi dreptunghic sunt a = 3 și b = 4. Cât măsoară ipotenuza c?

Ridicăm la pătrat cele două catete și le adunăm: 3² + 4² = 9 + 16 = 25.

Ipotenuza este radical din această sumă: c = √25 = 5.

✓ c = 5. Este tripletul clasic (3, 4, 5).
2
Ipotenuza unui triunghi dreptunghic este c = 10, iar o catetă este a = 6. Cât măsoară cealaltă catetă, b?

De data asta pornim invers: din pătratul ipotenuzei scădem pătratul catetei cunoscute: 10² − 6² = 100 − 36 = 64.

Cealaltă catetă este radical din acest rezultat: b = √64 = 8.

✓ b = 8. Tripletul (6, 8, 10) este dublul lui (3, 4, 5).
3
Un triunghi dreptunghic isoscel are ambele catete egale cu 1 (jumătate dintr-un pătrat tăiat pe diagonală). Cât măsoară ipotenuza?

Adunăm pătratele catetelor egale: 1² + 1² = 1 + 1 = 2.

Ipotenuza este c = √2 ≈ 1,41 - un număr care nu se termină niciodată exact.

✓ c = √2 ≈ 1,41. Așa arată diagonala oricărui pătrat cu latura 1.
4
Un triunghi are laturile 7, 24 și 25. Este el un triunghi dreptunghic?

Ridicăm la pătrat cele două laturi mai mici și le adunăm: 7² + 24² = 49 + 576 = 625.

Comparăm cu pătratul laturii celei mai mari: 25² = 625.

Cele două rezultate sunt egale, deci relația lui Pitagora este verificată.

✓ Da, este dreptunghic. (7, 24, 25) este un triplet pitagoreic.
5
O scară de 13 metri este sprijinită de un perete, cu piciorul scării la 5 metri distanță de perete. La ce înălțime pe perete ajunge scara?

Scara este ipotenuza unui triunghi dreptunghic, iar distanța de la perete este o catetă: 5 metri.

Scădem pătratul catetei cunoscute din pătratul ipotenuzei: 13² − 5² = 169 − 25 = 144.

Înălțimea este radical din acest rezultat: √144 = 12.

✓ Scara ajunge la 12 metri înălțime pe perete.
