Funcția sigma (suma divizorilor)

Euclid & Euler · nr. 149

Definiție: Funcția sigma σ(n) este suma tuturor divizorilor pozitivi ai lui n, inclusiv 1 și n însuși: σ(n)=∑_{d|n} d. Este o funcție multiplicativă: dacă gcd(m,n)=1, atunci σ(mn)=σ(m)σ(n).
Formulăσ(n) = ∑_{d|n} d
Imaginea din spatele formulei
Gândește-te la σ(n) ca la o listă cu toate „cutiile” de mărimi diferite în care poți împărți exact n obiecte, fără resturi - apoi aduni mărimile tuturor acestor cutii. Pentru numărul 12, cutiile posibile sunt de 1, 2, 3, 4, 6 și 12, iar suma lor este σ(12)=28 - pentru un număr prim, în schimb, ai doar două cutii posibile: cutia de 1 și cutia cât numărul însuși.
Funcția σ stă la baza definiției numerelor perfecte (σ(n)=2n), abundente (σ(n)>2n) și deficiente (σ(n)<2n). Euclid și Euler au folosit-o pentru a caracteriza complet numerele perfecte pare.
1
Calculează σ(12).

Găsim toți divizorii lui 12: 1, 2, 3, 4, 6, 12.

Îi adunăm: σ(12)=1+2+3+4+6+12.

Calculăm suma pas cu pas: 1+2=3, 3+3=6, 6+4=10, 10+6=16, 16+12=28.

✓ σ(12) = 28
2
Se știe că σ(n)=31 și că n este o putere a lui 2 (n=2ᵏ). Care este n?

Pentru n=2ᵏ, divizorii sunt 1,2,4,…,2ᵏ, iar suma lor este σ(n)=2^(k+1)−1 (o sumă geometrică).

Punem 2^(k+1)−1=31, deci 2^(k+1)=32.

Cum 32=2⁵, obținem k+1=5, adică k=4, deci n=2⁴=16.

✓ n = 16
3
Cât este σ(1), cazul cel mai mic posibil?

Singurul divizor pozitiv al lui 1 este 1 însuși.

Suma tuturor divizorilor este așadar doar 1.

✓ σ(1) = 1
4
Adevărat sau fals: σ(n) este întotdeauna un număr par, pentru orice n>1.

Luăm exemplul n=2, cel mai mic număr prim.

Divizorii lui 2 sunt 1 și 2, deci σ(2)=1+2=3.

3 este un număr impar, deci afirmația este falsă - există cel puțin un contraexemplu, chiar cel mai mic număr prim.

✓ Fals - σ(2)=3, care este impar.
5
Un elev vrea să verifice, folosind funcția σ, dacă 28 este un număr perfect. Calculează σ(28) și trage concluzia.

Divizorii lui 28 sunt 1, 2, 4, 7, 14 și 28.

Adunăm toți divizorii: σ(28)=1+2+4+7+14+28=56.

Comparăm cu 2×28=56: cele două valori sunt egale, deci 28 este un număr perfect, conform definiției σ(n)=2n.

✓ σ(28) = 56 = 2×28, deci 28 este perfect.
