Aria poligonului regulat

Euclid · nr. 029

Enunț: Aria unui poligon regulat cu n laturi de lungime l și apotema a (distanța de la centru la mijlocul fiecărei laturi) este egală cu jumătatea produsului dintre perimetru și apotemă.
FormulăS = (P · a) / 2 = (n · l · a) / 2
Imaginea din spatele formulei
Un poligon regulat (cu toate laturile și unghiurile egale) poate fi tăiat, ca un tort, în felii triunghiulare identice, pornind din centru spre fiecare latură. Aria fiecărei felii se calculează ușor (bază ori înălțime, împărțit la doi), iar aria întregului poligon este suma tuturor feliilor - adică jumătate din perimetru înmulțit cu „înălțimea” fiecărei felii, numită apotemă. Cu cât poligonul are mai multe laturi (mai multe felii, mai subțiri), cu atât seamănă mai mult cu un cerc.
Arhimede a calculat primele zecimale ale lui π aproximând cercul prin poligoane regulate cu 96 de laturi înscrise și circumscrise.
1
Un hexagon regulat are latura l=6 și apotema a=3√3. Calculează aria.

Calculăm perimetrul: P = n×l = 6×6 = 36.

Aplicăm formula: S = (P×a)/2 = (36×3√3)/2 = 54√3.

Aproximăm numeric: 54√3 ≈ 93,53.

✓ S = 54√3 ≈ 93,53
2
Un pătrat (poligon regulat cu n=4) are aria S=64 și apotema a=4. Cât măsoară perimetrul P și latura l?

Rearanjăm formula ca să scoatem perimetrul: P = 2S/a.

Înlocuim: P = 2×64/4 = 32.

Latura este perimetrul împărțit la numărul de laturi: l = P/4 = 32/4 = 8.

✓ P = 32, l = 8 (verificare: 8²=64 ✔, pătratul e caz particular de poligon regulat)
3
Un triunghi echilateral (poligon regulat cu n=3) are latura l=6. Găsește apotema și verifică aria cu formula poligonului regulat.

Apotema triunghiului echilateral este a = l√3/6 = 6√3/6 = √3.

Calculăm perimetrul: P = 3×6 = 18.

Aplicăm formula: S = (P×a)/2 = (18×√3)/2 = 9√3 ≈ 15,59.

✓ S = 9√3 (verificare cu formula directă: l²√3/4 = 36√3/4 = 9√3 ✔)
4
Adevărat sau fals: dacă dublezi numărul de laturi n al unui poligon regulat, păstrând aceeași lungime a laturii l, aria se dublează și ea.

Aria depinde de perimetrul P=n×l și de apotema a, iar apotema depinde ea însăși de n (a=l/(2tan(π/n))), nu este un număr fix când n se schimbă.

Dublarea lui n schimbă atât perimetrul cât și apotema, în moduri diferite, deci aria nu se dublează pur și simplu - poligonul devine, de fapt, mult mai mare per total.

✓ Fals. Mărirea numărului de laturi schimbă și apotema, nu doar perimetrul, deci relația nu este o simplă dublare.
5
Dacă numărul de laturi n al unui poligon regulat înscris într-un cerc de rază R crește spre infinit, spre ce formulă tinde aria poligonului?

Pe măsură ce n crește, perimetrul P se apropie tot mai mult de circumferința cercului, 2πR, iar apotema a se apropie de raza R.

Formula S=(P×a)/2 tinde deci spre (2πR×R)/2 = πR².

✓ Tinde spre S = πR² - exact aria cercului.
