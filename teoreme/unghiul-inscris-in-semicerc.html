Unghiul înscris în semicerc

Thales din Milet · nr. 021

Enunț (Teorema lui Thales despre cerc): Dacă AB este diametrul unui cerc și C este orice alt punct al cercului, atunci unghiul ACB este drept.
Formulă∡ACB = 90° (AB diametru)
Imaginea din spatele formulei
Imaginează-ți un cerc desenat pe podea, cu un baston pus exact pe mijloc, dintr-o margine în cealaltă (acesta este diametrul). Oriunde ai pune un al treilea copil pe marginea cercului și ai întinde sfori spre cele două capete ale bastonului, colțul format la copil este mereu exact un colț drept, ca de carte.
Chiar Thales a demonstrat această teoremă, iar legenda spune că, de bucurie pentru descoperire, a sacrificat un bou ca ofrandă.
1
AB=10 (diametru). AC=6. Găsește BC.

Pentru că AB este diametru, unghiul ACB este drept, conform teoremei.

Aplicăm teorema lui Pitagora în triunghiul dreptunghic ACB: AC²+BC²=AB².

Înlocuim: 6²+BC²=10², adică 36+BC²=100, deci BC²=64.

Extragem radical: BC=8.

✓ BC = 8
2
C este pe cerc, AB diametru. Unghiul CAB=40°. Găsește unghiul CBA.

Unghiul ACB este drept, pentru că este înscris în semicerc.

Suma unghiurilor din triunghiul ACB este 180°, deci CAB+CBA=180°−90°=90°.

Scădem: CBA=90°−40°=50°.

✓ CBA = 50°
3
Ce se întâmplă cu triunghiul ACB dacă punctul C alunecă pe cerc tot mai aproape de vârful A?

Unghiul ACB rămâne mereu 90°, indiferent unde se află C pe cerc, cât timp C este diferit de A și de B.

Dar latura AC devine tot mai scurtă, iar triunghiul se „turtește” tot mai mult.

Când C ajunge exact în A, triunghiul dispare complet - nu mai există trei vârfuri distincte.

✓ Unghiul rămâne 90° mereu, dar triunghiul devine tot mai turtit; la limită (C=A) nu mai există triunghi.
4
Adevărat sau fals: dacă punctul C nu este pe cerc, ci undeva strict în interiorul discului, iar AB rămâne diametru, unghiul ACB este tot 90°.

Teorema unghiului înscris în semicerc este valabilă doar pentru puncte C aflate exact pe cerc.

Dacă C este în interiorul discului, unghiul ACB devine mai mare de 90° (obtuz) - punctul „vede” diametrul sub un unghi mai larg.

✓ Fals. În interiorul cercului, unghiul ACB este obtuz, nu drept.
5
Un desenator vrea să traseze un unghi drept perfect, fără echer, folosind doar compasul și rigla. Cum poate folosi această teoremă?

Desenează un cerc oarecare și alege un diametru AB (o linie dreaptă prin centru).

Alege orice alt punct C pe cerc și îl unește cu A și cu B.

Conform teoremei, unghiul ACB este garantat drept, indiferent de punctul C ales.

✓ Orice punct C de pe cerc, unit cu capetele unui diametru, formează un unghi drept - o metodă veche de construcție geometrică.
