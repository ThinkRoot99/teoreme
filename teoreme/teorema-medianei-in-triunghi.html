Teorema medianei

Apollonius, ~200 î.Hr. · nr. 008

Enunț: Lungimea medianei mₐ din vârful A la mijlocul M al laturii BC, exprimată prin laturile triunghiului.
Formulămₐ² = (2b² + 2c² − a²) / 4
Imaginea din spatele formulei
Mediana e firul care unește un colț al triunghiului exact cu mijlocul laturii din fața lui. Lungimea ei nu depinde doar de latura pe care cade, ci „simte” toate cele trei laturi ale triunghiului - ca și cum ar fi un fir întins care se lasă tras de fiecare colț în parte. De aceea formula ei folosește toate trei lungimile, nu doar una.
Apollonius a demonstrat că suma pătratelor celor trei mediane este egală cu trei sferturi din suma pătratelor laturilor.
1
Un triunghi are laturile a = 6, b = 5, c = 7. Cât măsoară mediana mₐ, dusă spre latura a?

Aplicăm formula: mₐ² = (2b² + 2c² − a²) / 4.

Înlocuim: mₐ² = (2×25 + 2×49 − 36) / 4 = (50 + 98 − 36) / 4 = 112/4 = 28.

Extragem radical: mₐ = √28 = 2√7 ≈ 5,29.

✓ mₐ ≈ 5,29
2
Un triunghi are a = 10, b = c (este isoscel), iar mediana mₐ = 6. Cât măsoară b?

Cu b = c, formula se simplifică: mₐ² = (4b² − a²)/4 = b² − a²/4.

Înlocuim: 36 = b² − 100/4 = b² − 25, deci b² = 61.

Extragem radical: b = √61 ≈ 7,81.

✓ b ≈ 7,81
3
Ce se întâmplă cu mediana mₐ dintr-un triunghi dreptunghic 3-4-5, dusă chiar spre ipotenuza a = 5?

Aplicăm formula cu b = 3, c = 4, a = 5: mₐ² = (2×9 + 2×16 − 25)/4 = (18+32−25)/4 = 25/4.

Extragem radical: mₐ = 2,5.

Observăm că 2,5 este exact jumătate din ipotenuza 5.

✓ mₐ = 2,5 = a/2. La orice triunghi dreptunghic, mediana spre ipotenuză e jumătate din ipotenuză.
4
Adevărat sau fals: mediana dintr-un vârf împarte întotdeauna triunghiul în două triunghiuri cu arii egale.

Mediana unește vârful cu mijlocul laturii opuse, deci cele două triunghiuri formate au baze egale (jumătățile laturii) și aceeași înălțime (din vârf).

Arie = bază × înălțime / 2, iar bazele egale și înălțimea comună dau arii egale.

✓ Adevărat. Orice mediană împarte triunghiul în două jumătăți de arii egale.
5
Un triunghi are laturile a = 8, b = 6, c = 6. O rudă de-a ta spune că mediana spre a este mai lungă decât 4. Are dreptate?

Aplicăm formula: mₐ² = (2×36 + 2×36 − 64)/4 = (72+72−64)/4 = 80/4 = 20.

Extragem radical: mₐ = √20 = 2√5 ≈ 4,47.

Comparăm cu 4: 4,47 > 4.

✓ Da, are dreptate: mₐ ≈ 4,47, mai mare decât 4.
