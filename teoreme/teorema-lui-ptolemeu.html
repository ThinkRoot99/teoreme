Teorema lui Ptolemeu

Claudius Ptolemeu, ~150 d.Hr. · nr. 015

Enunț: Într-un patrulater inscriptibil (înscris într-un cerc), produsul diagonalelor este egal cu suma produselor laturilor opuse: AC·BD = AB·CD + AD·BC.
FormulăAC · BD = AB · CD + AD · BC
Imaginea din spatele formulei
Desenează patru puncte pe un cerc și unește-le, formând un patrulater cu colțuri pe cerc. Trage și cele două diagonale, care se încrucișează în mijloc. Produsul lungimilor celor două diagonale este mereu egal cu suma produselor laturilor opuse - un echilibru ascuns, valabil doar când toate cele patru puncte sunt exact pe același cerc.
Claudius Ptolemeu (~150 d.Hr.) a utilizat această teoremă în cartea sa „Almagest” pentru a deduce formulele sinusului și cosinusului sumei de unghiuri.
1
Un dreptunghi are laturile 3 și 4. Verifică teorema lui Ptolemeu pentru diagonalele lui.

Un dreptunghi este mereu inscriptibil (are toate colțurile pe un cerc), iar cele două diagonale sunt egale, notate d.

Laturile opuse dreptunghiului sunt 3 și 3, respectiv 4 și 4.

Ptolemeu: d×d = 3×3 + 4×4 = 9+16 = 25, deci d = 5 - exact rezultatul lui Pitagora.

✓ d² = 25, adică d = 5. Ptolemeu confirmă Pitagora pentru dreptunghi.
2
Un patrulater inscriptibil are laturile AB=2, BC=3, CD=4, DA=5. Cât este produsul diagonalelor AC·BD?

Aplicăm direct formula lui Ptolemeu: AC·BD = AB·CD + AD·BC.

Înlocuim: AC·BD = 2×4 + 5×3 = 8+15 = 23.

✓ AC · BD = 23
3
Un pătrat cu latura a. Calculează diagonala d folosind teorema lui Ptolemeu.

Toate laturile pătratului sunt egale cu a, iar cele două diagonale sunt egale între ele, notate d.

Ptolemeu: d×d = a×a + a×a = 2a².

Extragem radical: d = a√2.

✓ d = a√2 - formula binecunoscută a diagonalei pătratului.
4
Adevărat sau fals: dacă pentru un patrulater oarecare produsul diagonalelor este mai mare decât suma produselor laturilor opuse, patrulaterul poate fi inscriptibil.

Inegalitatea lui Ptolemeu spune că, pentru orice patrulater, AC·BD ≤ AB·CD + AD·BC, cu egalitate exact atunci când patrulaterul este inscriptibil.

A avea produsul diagonalelor strict mai mare ar încălca această inegalitate.

✓ Fals. O asemenea situație este imposibilă geometric.
5
Un trapez isoscel inscriptibil are bazele 6 și 14, iar laturile oblice de 5. Calculează diagonala d.

Trapezul isoscel este inscriptibil, iar cele două diagonale sunt egale.

Ptolemeu: d² = 6×14 + 5×5 = 84+25 = 109.

Extragem radical: d = √109 ≈ 10,44.

✓ d ≈ 10,44
