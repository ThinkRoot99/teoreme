Numerele Mersenne

Marin Mersenne, 1644 · nr. 070

Definiție: Numărul Mersenne Mₙ=2ⁿ−1. Dacă n este compus, Mₙ este compus. Dacă n este prim, Mₙ poate fi prim (dar nu este garantat).
FormulăMₙ = 2ⁿ − 1
Imaginea din spatele formulei
Pornește cu 1 bomboană și dublează-le mereu: 1, 2, 4, 8, 16, 32, … De fiecare dată când te oprești după n dublări, ia toate bomboanele obținute și scade doar una singură. Așa obții numerele Mersenne, Mₙ=2ⁿ−1: de exemplu, dublând de 3 ori pornind de la 1 ajungi la 8, iar 8−1=7 este chiar M₃, un număr Mersenne prim.
Marin Mersenne a listat primele de această formă încă din 1644, iar numerele perfecte pare sunt strâns legate de primele Mersenne: 2^(p-1)×(2^p-1), cu 2^p-1 prim.
1
Calculează M₈ și verifică dacă este prim.

M₈=2⁸−1=256−1=255.

255 se împarte exact la 3: 255=3×85, deci 255 nu este prim.

Acest lucru era de așteptat, pentru că 8 este un număr compus (8=2×4), iar dacă n este compus, Mₙ este automat compus.

✓ M₈=255, compus
2
Se știe că un număr Mersenne este Mₙ=127. Care este n?

Căutăm n astfel încât 2ⁿ−1=127, adică 2ⁿ=128.

Calculăm puterile lui 2: 2⁷=128.

Deci n=7.

✓ n = 7
3
Cât este M₁, și este el prim?

M₁=2¹−1=2−1=1.

Numărul 1 nu este considerat, prin definiție, nici prim, nici compus.

Deci M₁=1 este un caz special, în afara discuției despre numere prime Mersenne.

✓ M₁ = 1, nici prim, nici compus
4
Adevărat sau fals: dacă n este un număr prim, atunci Mₙ=2ⁿ−1 este garantat prim.

Luăm n=11, care este un număr prim.

Calculăm M₁₁=2¹¹−1=2048−1=2047.

Verificăm: 2047=23×89, deci 2047 este compus, deși 11 este prim.

Acest exemplu arată clar că n prim nu garantează că Mₙ este prim - este doar o condiție necesară, nu suficientă.

✓ Fals - contraexemplu: n=11 prim, dar M₁₁=2047=23×89 este compus.
5
Un cercetător care caută numere prime Mersenne (ca în proiectul GIMPS) verifică exponentul n=13. Ce număr Mersenne trebuie testat, și cât este el?

Calculăm M₁₃=2¹³−1.

2¹³=8192, deci M₁₃=8192−1=8191.

Acest număr, 8191, este într-adevăr un număr prim Mersenne cunoscut.

✓ M₁₃ = 8191, un număr prim Mersenne.
