Legea cosinusurilor

François Viète, sec. XVI · nr. 005

Enunț: Într-un triunghi cu laturile a, b, c și unghiurile opuse A, B, C, pătratul fiecărei laturi egal cu suma pătratelor celorlalte două laturi minus dublul produsului lor cu cosinusul unghiului cuprins.
Formulăa² = b² + c² − 2bc·cosA
Imaginea din spatele formulei
Când un triunghi are un colț drept, folosim Pitagora. Dar ce facem când colțul e „strâmb” - mai ascuțit sau mai deschis decât un colț drept? Legea cosinusurilor este un Pitagora „corectat”: ia formula obișnuită a²+b²+c² și adaugă o corecție care ține cont de cât de deschis este unghiul dintre cele două laturi. Dacă unghiul este chiar de 90°, corecția dispare complet și rămânem cu Pitagora.
Utilizată în topografie, navigație și fizică pentru a calcula distanțe și unghiuri în triunghiuri obtuze sau ascuțite.
1
Un triunghi are laturile b = 5, c = 7 și unghiul dintre ele A = 60°. Cât măsoară latura a, opusă acestui unghi?

Aplicăm formula: a² = b² + c² − 2bc·cosA.

Înlocuim numerele: a² = 25 + 49 − 2×5×7×cos60° = 74 − 70×0,5 = 74 − 35 = 39.

Extragem radical: a = √39 ≈ 6,24.

✓ a ≈ 6,24
2
Un triunghi are laturile a = 8, b = 5 și c = 7. Cât măsoară unghiul A, opus laturii a?

Rearanjăm formula ca să scoatem cosinusul: cosA = (b² + c² − a²) / (2bc).

Înlocuim: cosA = (25 + 49 − 64) / (2×5×7) = 10/70 = 1/7.

Folosim funcția inversă arccos pentru a afla unghiul: A = arccos(1/7) ≈ 81,8°.

✓ A ≈ 81,8°
3
Ce se întâmplă cu legea cosinusurilor dacă unghiul A este chiar 90°?

Știm că cos90° = 0.

Termenul de corecție −2bc·cosA devine −2bc×0 = 0 și dispare din formulă.

Rămâne exact a² = b² + c², adică teorema lui Pitagora.

✓ Legea cosinusurilor devine teorema lui Pitagora - Pitagora este doar un caz particular.
4
Adevărat sau fals: dacă unghiul A este obtuz (mai mare de 90°), latura a este mai scurtă decât ar fi la un unghi drept.

Pentru unghiuri obtuze, cosA este negativ, deci −2bc·cosA devine pozitiv și se adaugă la b²+c².

Asta face ca a² - și deci a - să fie mai mare decât în cazul unghiului drept, nu mai mic.

✓ Fals. Un unghi obtuz face latura opusă mai lungă, nu mai scurtă.
5
Doi drumeți pornesc din același punct: unul merge 7 km spre est, celălalt 9 km pe o direcție care face un unghi de 120° cu prima. Cât de departe unul de celălalt ajung?

Cele două trasee sunt laturile b = 7 și c = 9 ale unui triunghi, cu unghiul A = 120° între ele.

Aplicăm legea cosinusurilor, știind că cos120° = −0,5: a² = 49 + 81 − 2×7×9×(−0,5) = 130 + 63 = 193.

Extragem radical: a = √193 ≈ 13,89.

✓ Distanța dintre drumeți este de aproximativ 13,89 km.
