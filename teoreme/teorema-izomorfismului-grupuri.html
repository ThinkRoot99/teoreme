Prima teoremă de izomorfism

formalizată de Emmy Noether, 1927 · nr. 151

Enunț: Fie f:G→H un omomorfism de grupuri. Atunci nucleul Ker(f)={g∈G : f(g)=e_H} este subgrup normal al lui G, iar grupul cât G/Ker(f) este izomorf cu imaginea Im(f)={f(g) : g∈G}.
FormulăG/Ker(f) ≅ Im(f)
Imaginea din spatele formulei
Gândește-te la o mașinărie care sortează jucării în cutii etichetate: toate jucăriile care ajung în „cutia zero” (nucleul) sunt tratate identic de mașinărie. Dacă „lipești” împreună toate jucăriile din aceeași cutie și le privești ca pe un singur obiect, obții exact aceleași forme care ies de fapt din mașinărie (imaginea) - de-asta grupul „lipit” G/Ker(f) arată identic cu Im(f).
Deși structura de bază era cunoscută încă din secolul XIX, formularea modernă, axiomatică, aparține lui Emmy Noether (1927), care a arătat că aceeași teoremă funcționează identic pentru inele, module și alte structuri algebrice.
1
f:ℤ→ℤ/5ℤ, f(x)=x mod 5. Determină Ker(f), Im(f) și verifică teorema.

Nucleul este mulțimea numerelor întregi care dau restul 0 la împărțirea cu 5, adică Ker(f)={x∈ℤ : x este multiplu de 5}=5ℤ.

Imaginea este toată mulțimea ℤ/5ℤ, deoarece orice rest de la 0 la 4 se obține pentru un x potrivit (funcția este surjectivă).

Teorema spune ℤ/Ker(f)≅Im(f), adică ℤ/5ℤ≅ℤ/5ℤ - exact adevărat.

✓ ℤ/5ℤ ≅ ℤ/5ℤ, confirmat
2
Un omomorfism f:ℤ→ℤ are Ker(f)={0} și Im(f)=3ℤ. Ce izomorfism garantează teorema, fără să cunoști formula exactă a lui f?

Teorema garantează ℤ/Ker(f)≅Im(f), iar cu Ker(f)={0}, avem ℤ/{0}≅ℤ.

Deci concluzia este ℤ≅3ℤ - grupul întregilor este izomorf cu grupul multiplilor lui 3, indiferent de formula exactă a lui f, atât timp cât Ker și Im sunt cele date.

✓ ℤ ≅ 3ℤ
3
f:ℝ*→ℝ*, f(x)=x². Determină Ker(f) și Im(f) (caz special, nucleul nu e trivial).

Rezolvăm f(x)=1: x²=1 are exact două soluții, x=1 și x=-1, deci Ker(f)={1,-1} - un caz special în care nucleul nu este trivial.

Imaginea este ℝ₊* (numerele reale strict pozitive), deoarece x² este întotdeauna pozitiv, iar orice număr pozitiv are o rădăcină pătrată reală.

✓ ℝ*/{±1} ≅ ℝ₊*
4
Adevărat sau fals: dacă Ker(f)={e}, atunci f este neapărat surjectivă.

Ker(f)={e} înseamnă doar că f este injectivă (elemente distincte merg în elemente distincte) - nu spune nimic despre cât de „mare” este imaginea.

Contraexemplu: f:ℤ→ℤ, f(x)=2x are Ker(f)={0} (e injectivă), dar Im(f)=2ℤ, strict mai mică decât ℤ - f nu e surjectivă, deci afirmația e falsă.

✓ Fals - injectivitatea nu implică surjectivitatea
5
sgn:S₃→{±1} asociază fiecărei permutări +1 (pară) sau -1 (impară). Verifică teorema izomorfismului pentru acest exemplu (|S₃|=6).

Nucleul funcției semn este mulțimea permutărilor pare, A₃={e,(123),(132)}, cu 3 elemente.

Imaginea este {+1,-1}, cu 2 elemente, iar |S₃/A₃|=6/3=2, exact cât |Im(f)|.

Teorema confirmă: S₃/A₃≅{±1}.

✓ S₃/A₃ ≅ {±1}, ambele de ordin 2
