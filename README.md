# ∑ Teoreme

Enciclopedie matematică gratuită în limba română: 188 de teoreme din 8
domenii (geometrie, aritmetică, algebră, analiză, probabilitate,
topologie, combinatorică, logică), fiecare cu definiție formală,
diagramă, explicație intuitivă și 5 exerciții rezolvate pas cu pas.

Site static, fără backend, fără bază de date. Funcționează și fără
JavaScript (conținutul e randat static în fiecare pagină HTML) și e
testat pentru compatibilitate cu browsere vechi de ~10 ani.

(conținutul: text și diagrame).

Pentru instalare, structura fișierelor și cum se adaugă o teoremă nouă,
vezi [CONTRIBUTING.md](CONTRIBUTING.md).
